# 小米运动健康 → Apple 健康 迁移工具

把本地导出的小米运动健康数据，离线转换成导入包，再用 iPhone 上的 App 写入 Apple 健康。整个工具不联网、不上传、不做遥测。

## 需要准备

- 一台能运行 Python 3 的电脑
- 一份本地的小米运动健康导出目录（只读取用）
- iPhone（iOS 16 或更高版本），能安装 TrollStore
- 没有 Mac 也可以用仓库里的 GitHub Actions 工作流构建安装包

## 使用步骤

### 1. 生成导入集

在仓库目录下执行（两个路径都是占位符，换成你自己的本地目录；输出目录不能与导出目录相同或位于其内部）：

```bash
python -B converter/build_import_set.py --input "<导出目录>" --output-dir "<输出目录>"
```

生成的目录里有一个清单文件和 `parts/` 分包目录，两者必须保持原有层级和文件名。

### 2. 构建并安装 App

在 GitHub 仓库的 Actions 页面手动运行 **Build TrollStore IPA**，下载产物，用 TrollStore 安装到 iPhone。

### 3. 把导入集传到 iPhone

把**整个生成目录**拷贝到 iPhone「文件」App 能访问的位置。不要只拷单个 JSON，不要改文件名，不要拆分目录。这一步是本地传输，不要上传到任何在线服务。

### 4. 在 App 里导入

1. 打开 App，首次使用时允许健康数据写入权限。
2. 点「选择正式导入目录」，**一次选中整个目录**（不要点「选择单个 JSON 导入包」）。
3. 点「检查写入权限」，确认各类型均为「已允许」。这一步不写入数据。
4. 点「开始完整导入」。保持 App 在前台并接上电源，数据量大时耗时较长。

**中断了**：重新选择同一个目录，点「从断点继续导入」，已完成的分包会自动跳过。
**有失败分包**：点「重试失败的 N 个分包」，不会重复写入已存在的记录。

全部完成、失败数为 0 即结束。

## 隐私

- 原始导出目录只会被读取，不会被修改、移动或删除。
- 导入集、清单、审计报告、安装包、截图与日志都保留在本地，**不要提交到仓库、不要上传到任何网站**。
- 单位或含义无法确证的字段不会被写入 Apple 健康，也不会被猜测；原因记录在本地生成目录的审计报告里。
