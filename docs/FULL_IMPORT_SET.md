# 完整导入集

完整迁移使用一个本地目录：

```text
导入目录/
  import-manifest.json
  parts/
    part-0001.json
    part-0002.json
```

`converter/build_import_set.py` 在本机流式生成该目录。清单记录每个分包的文件名、SHA-256、记录数、类型和日期范围；不应包含健康测量值、账号标识或本机路径。

iPhone App 选择目录一次后，会按清单顺序逐包校验摘要、读取、写入并释放内存。完成分包会在 App 内记录，以便中断后继续；重试时会依据同步标识跳过已经写入的记录。

不要改名、移动或单独传输 `parts/` 下的文件。整个目录、清单和审计报告均属于私有数据，应保留在本地与 iPhone 文件系统中，不得提交到公开仓库。
