# 隐私边界

本项目的设计目标是让个人健康数据只留在用户自己的电脑和 iPhone 上。

## 公开仓库与 CI

- 不提交原始导出、导入包、数据库、截图、IPA、备份、设备/账号标识或真实测量值。
- Issue、PR、构建日志和截图同样不得包含个人健康数据。
- GitHub Actions 只处理公开源码；它不应下载、转换、校验或上传任何用户导出。
- 发布前必须运行 `scripts/release_preflight.py`。该检查不能替代人工审阅，但会拒绝常见的原始数据、生成物和本机路径。

## 本地数据流

```text
本地小米导出 → 本地转换器 → 本地完整导入目录 → 用户手动传入 iPhone → HealthKit
```

App 不提供账号登录、遥测、网络上传或后台扫描。HealthKit 写入必须由用户在预览后明确确认。

## 不确定数据

字段的单位、语义或 Apple Health 对应类型无法证实时，转换器应跳过该字段并写入本地审计说明，而不是猜测或伪造数据。
